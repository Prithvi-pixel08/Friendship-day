

Special Letter

This folder contains the original Python/Tkinter source and a browser-ready video render of its animation.

- "letter.py" — Original animation source from the SpecialLetter repository.
- "letter.mp4" — Rendered animation, cropped to the original application window for display on the website.
- "letter.css" and "letter.js" — Full-screen overlay and playback controls.

GitHub Pages cannot execute a Tkinter desktop application in a visitor's browser. The original Python program was therefore run during preparation and its animation rendered to MP4. The website plays that original animation after the visitor selects One last little thing at the end of the Friendship Day page.

To change the closing line, edit "FINAL_NOTE" in "letter.js".
Preview deployment trigger for Special Letter integration.
